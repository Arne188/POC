# Hooked Ad Assistant 2.0

Android-Hilfe für Hooked Inc. / Rewarded Ads. **Keine automatischen Klicks.**

## Funktionen
- Accessibility/UI-Erkennung für Close / Skip / Continue / Weiter / Schließen
- lokale Screenshot-Heuristik für X-Symbole in den oberen Display-Ecken
- Timer-Fallbacks nach 35 und 60 Sekunden
- 2-Treffer-Filter + 7-s-Cooldown gegen Alarm-Spam
- Statistik für erkannte Ad-Sessions, Alarmzahl, Durchschnittsdauer und Crown-XP-Schätzung
- Schalter für Erkennungsmethoden und Vibration
- Ziel-App: `se.ace.fishinc`

Screenshots werden nur im Arbeitsspeicher analysiert, nicht gespeichert oder übertragen.
